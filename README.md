# Odyssey Mouse

Samsung Odyssey（Windows Mixed Reality）モーションコントローラを、**マウス代わりに使う常駐アプリ**です。
Bluetooth で接続したコントローラのタッチパッド／スティックを直接読み取り（HID）、
Windows 標準の入力 API（`SendInput`）でカーソル・クリック・スクロールを操作します。

- **ドライバ不要**。アンインストールすれば元通り
- **管理者権限なし**でインストール（ユーザー単位・自己完結の 1 ファイル）
- **日本語 / 英語** UI 切替
- 軽タッチの **タップでクリック**、クリック時の**振動フィードバック**（既定 OFF）
- 感度プリセット（精密 / 標準 / 速い）＋ **ライブモニタ**でチューニング
- タスクトレイ常駐、**Ctrl+Alt+M** でいつでも有効/無効

## ダウンロードとインストール

[Releases](../../releases/latest) から `OdysseyMouseSetup.exe` を取得して実行してください。

1. `OdysseyMouseSetup.exe` を実行（UAC なし・スタートメニューとデスクトップにショートカットを作成）
2. コントローラを Windows の **Bluetooth 設定**で「Motion controller」として接続
3. 「Odyssey Mouse」を起動し、コントローラの **Windows ボタン**を押す
   → 自動で中心を校准して開始します（画面上部の状態が「接続中」になれば OK）

アンインストールはスタートメニューの「Odyssey Mouse」→「Odyssey Mouse をアンインストール」。
設定は `%APPDATA%\OdysseyMouse\settings.ini` に残るので、入れ直しても好みが引き継がれます。

## 動作要件

| 項目 | 内容 |
| --- | --- |
| OS | Windows 10 / 11（.NET Framework 4.8 — OS に付属） |
| 接続 | Bluetooth |
| デバイス | WMR モーションコントローラ（`045E:065D`／Samsung Odyssey 右コントローラで検証） |
| 権限 | 不要（ただし UAC ダイアログなど管理者画面には送れないため、必要なら「管理者として再起動」） |

## ボタンの割り当て

| 操作 | 動作 |
| --- | --- |
| スティック / タッチパッド | カーソル移動 |
| タッチパッドを軽くタップ | 左クリック |
| パッド押込 / トリガー | 左ボタン（押している間はドラッグ） |
| グリップ | 右ボタン |
| スティック押込 | 中ボタン |
| メニュー | スクロールモード切替（中はスティックでホイール、上＝上スクロール） |
| Windows | 押している間だけ速度ブースト |

すべて設定画面の「詳細」タブで変更できます。

## 知っておいてほしいこと

- タッチパッドの中心付近ではタップが反応しません（中心は「触れていない」と同じ値になるため）。少しずらして叩いてください。
- タッチパッドの分解能は約 100 段階（実測 101 段階）です。細かい作業は 12bit のスティックの方が有利なことがあります。
- 管理者権限で動く画面（UAC のダイアログ等）には入力を送れません。
- Bluetooth が不安定で切断することがあります。切断しても自動で再接続します。頻発する場合は電池（単4×2）を交換してください。
- プレイ中のゲームによっては、この方式のカーソル移動を無視することがあります。

## ビルド

```
cd app
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

必要なものだけ:

- .NET Framework 4.8 以上（OS に付属）
- C# コンパイルが動くこと（Visual Studio Build Tools の Roslyn `csc.exe`、
  なければ `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` でも可）

**`.NET SDK` は不要**です。参照アセンブリフォルダも不要（実 dll を直接指定します）。
オプション: `-SkipInstaller` `-SkipIcon`

詳しい手順は [app/README.md](app/README.md) を参照してください。

| パス | 内容 |

## 既知の制限

- `SendInput` 方式のため、**管理者として実行している画面には入力を送れません**（UIPI）。
- ドライバではないので、ゲーム側が独自に入力を読んでいる場合は動かないことがあります。
- コントローラは Bluetooth のため、電池切れ・圏外で切断することがあります（自動再接続します）。
